# Convenção de Commits

- Todas as mensagens de commit devem ser escritas obrigatoriamente em **português**.
- Seguir o padrão Conventional Commits (ex: `fix: ...`, `feat: ...`, `docs: ...`, `refactor: ...`).
- Exemplos:
  - `fix: limita o tamanho da resposta HTTP do cron`
  - `feat: adiciona suporte a crons separados por canal`
  - `docs: atualiza documentação do projeto`
