# Regra de Documentação do Projeto (`docs/`)

- **Estrutura Obrigatória:** Todos os projetos devem possuir um diretório `docs/` na raiz.
- **Conteúdo Essencial:** A pasta `docs/` deve conter e manter atualizados os seguintes tópicos e arquivos:
  - `docs/configuracoes_iniciais.md`: Requisitos do sistema, instalação de dependências, variáveis de ambiente e passos para rodar o projeto.
  - `docs/licoes_aprendidas.md`: Registro contínuo de desafios técnicos, decisões de arquitetura, correções de bugs complexos e boas práticas aprendidas ao longo do desenvolvimento.
  - `docs/arquitetura.md` (e outros docs específicos): Detalhamento do fluxo do sistema, diagramas, integrações com APIs externas e schemas de dados.
- **Manutenção Contínua:** Sempre que novas configurações forem adicionadas ou novas lições/decisões forem consolidadas, a pasta `docs/` deve ser prontamente atualizada.
